# Correção RC2.1 — Datas independentes

- **Data de entrega:** data em que a entrega relacionada ao DNR ocorreu.
- **Data de abertura do DNR:** data em que o DNR foi aberto.
- **Prazo para concluir a análise:** calculado exclusivamente como **data do upload do lote + 3 dias**.

Os filtros por dia, intervalo, semana, ano e base podem usar Data de entrega ou Data de abertura do DNR. Nenhum desses filtros altera o SLA operacional.
