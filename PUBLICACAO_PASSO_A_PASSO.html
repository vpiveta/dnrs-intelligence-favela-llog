DNR's Intelligence Favela Llog — Publicação

1. GitHub

  1. Execute PUBLICAR_SISTEMA.bat.
  2. Autorize o GitHub quando o navegador solicitar.
  3. Confirme que o repositório recebeu as pastas app, scripts e os arquivos de configuração.

2. Supabase

  1. Crie um projeto gratuito.
  2. Abra Connect e copie a URL do Session Pooler.
  3. Guarde essa URL; ela será a variável DATABASE_URL.

3. Render

  1. Crie um Web Service ligado ao repositório vpiveta/flip-enterprise.
  2. O Render detectará render.yaml.
  3. Cadastre DATABASE_URL com a URL do Supabase.
  4. Faça o deploy.

4. Levar os dados atuais

  1. Execute ASSISTENTE_PUBLICACAO_WEB.bat.
  2. Escolha a opção 5.
  3. Cole a URL do Supabase.
  4. Aguarde a migração concluir.

Depois disso, todas as bases acessarão o mesmo endereço do Render.
