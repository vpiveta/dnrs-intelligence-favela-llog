# Enterprise 2.0.1 — Filtro Global Persistente

- Contexto por sessão: Base, Data de entrega, Semana e Ano.
- Dashboard, Analytics, Casos, Sala de Guerra, Inteligência e GEO reutilizam o mesmo contexto.
- Cards semanais substituem o contexto global.
- Barra visível mostra o filtro ativo e permite limpar.
- Usuários de base permanecem limitados à própria operação.
