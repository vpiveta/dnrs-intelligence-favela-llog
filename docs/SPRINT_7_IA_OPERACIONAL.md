# Sprint 7 — IA Operacional e Sala de Guerra

Esta versão acrescenta uma tela gerencial com:

- score automático por caso;
- alertas de SLA, reincidência, ausência de procedimento e valor;
- comparação semanal de endereços, motoristas, logins e produtos;
- comparação consolidada entre bases;
- eficiência dos procedimentos;
- links diretos para casos, mapa e inteligência.

O cálculo é determinístico e explicável: cada score mostra os fatores que contribuíram para a classificação.
