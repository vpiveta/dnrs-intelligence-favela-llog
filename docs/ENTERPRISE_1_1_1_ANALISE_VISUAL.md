# Enterprise 1.1.1 — Análise e Visual

- Reincidências abrem somente os IDs dos DNRs que formaram a análise.
- Cliente reincidente = base + nome normalizado + endereço normalizado.
- Endereços iguais são agrupados em um marcador para acelerar o GEO.
- Gráficos usam paleta moderna e o ranking de motoristas limita a 12 nomes, agrupando o restante em Outros.
- Navegação da lista analisada preserva a tela de origem.
